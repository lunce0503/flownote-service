# Flownote Windows 1.3.1

- 전공서 PDF를 분야별 책장에 보관하고 표지·이어 읽기·페이지 책갈피를 사용합니다.
- 최대 100MiB 원본 PDF를 내보내며 앱 재시작과 업데이트 후 기기 자료를 유지합니다.
- 책장 PDF와 읽기 기록은 현재 앱의 계정별 기기에 저장됩니다. 다른 기기로 자동 동기화되지 않습니다.
- Electron 런타임을 44.9.0으로 갱신합니다.

## 1.2.0

- 동기화를 끄기 전에 서버 노트·캔버스·이미지·플래너를 기기에 저장하고 오프라인에서 이어서 편집합니다.
- 다시 켜면 공통 기준본 이후의 변경을 조정해 업로드하며, 같은 자료의 충돌은 의미 있는 편집량이 더 큰 버전을 반영합니다.
- 선택되지 않은 충돌 버전과 기존 기기 전용 초안은 JSON 백업에서 복구할 수 있도록 보존합니다.
- 네트워크 단절 시 조정 계획과 진행 위치를 저장해 같은 작업을 안전하게 재시도합니다.

## 1.1.1

GitHub CDN의 수동 redirect 응답을 Electron net.fetch가 취소하던 자동 다운로드 오류를 수정했습니다. Node fetch로 응답을 검사하며 기존 HTTPS redirect allow-list와 서명/해시 검증은 유지합니다. 1.0.0 또는 초기 1.1.0 사용자는 이번 1.1.1을 직접 설치하세요.

## 1.1.0

- 캔버스·노트의 베이지·흰색·검정 디자인과 폴더 탐색을 웹과 함께 사용합니다.
- 시작·재개·매시간 새 버전을 확인하고 서명과 SHA-256 검증 후 자동 다운로드합니다.
- 도움말의 업데이트 메뉴에서 변경 내용, 진행 상태, 확인/다운로드 이력과 재시도를 확인합니다.
- 설치형은 사용자 확인 후 설치 프로그램을 실행합니다. 포터블은 검증된 ZIP을 내려받고 직접 압축 해제합니다.
- 기존 로그인·초안·자료를 보존합니다. 1.0.0에는 업데이트 기능이 없어 이번 버전은 한 번 직접 설치해야 합니다.
- Windows 게시자 Authenticode 서명은 없습니다. 향후 업데이트는 앱에 고정한 별도 RSA 공개키로 릴리스 서명을 검증합니다.

## 1.0.0

Windows 10/11 x64용 Flownote 앱의 첫 릴리즈입니다.

- 기존 웹의 노트 편집기, 캔버스, 플래너 및 등록된 기능을 같은 계정으로 사용합니다.
- 아이보리·검정 디자인, 기존 웹 헤더 제거, 창 크기에 맞춘 왼쪽/하단 탐색을 제공합니다.
- Windows 편집 단축키, 전체 화면, 파일 선택 및 파일 저장을 지원합니다.
- 앱을 다시 열어도 로그인 상태를 유지합니다.

설치형은 `Flownote-Setup-1.0.0-x64.exe`를 실행합니다. 포터블은 ZIP 전체를 압축 해제하고 `Flownote.exe`를 실행합니다. 인터넷 연결이 필요합니다. 서버에서 중지되거나 개발 중인 기능의 상태는 웹과 같습니다.

Windows 게시자 코드서명 인증서는 적용하지 않았습니다. 파일 해시는 `SHA256SUMS.txt`로 확인할 수 있습니다. 설치 안내: https://flownote-react.vercel.app/windows.html
