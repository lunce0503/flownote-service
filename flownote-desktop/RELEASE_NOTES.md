# Flownote Windows 1.0.0

Windows 10/11 x64용 Flownote 앱의 첫 릴리즈입니다.

- 기존 웹의 노트 편집기, 캔버스, 플래너 및 등록된 기능을 같은 계정으로 사용합니다.
- 아이보리·검정 디자인, 기존 웹 헤더 제거, 창 크기에 맞춘 왼쪽/하단 탐색을 제공합니다.
- Windows 편집 단축키, 전체 화면, 파일 선택 및 파일 저장을 지원합니다.
- 앱을 다시 열어도 로그인 상태를 유지합니다.

설치형은 `Flownote-Setup-1.0.0-x64.exe`를 실행합니다. 포터블은 ZIP 전체를 압축 해제하고 `Flownote.exe`를 실행합니다. 인터넷 연결이 필요합니다. 서버에서 중지되거나 개발 중인 기능의 상태는 웹과 같습니다.

Windows 게시자 코드서명 인증서는 적용하지 않았습니다. 파일 해시는 `SHA256SUMS.txt`로 확인할 수 있습니다. 설치 안내: https://flownote-react.vercel.app/windows.html
