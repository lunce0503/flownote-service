# Flownote Remote 0.6.0 · 휴대폰 터치 리모컨

제스처 명령을 중지하고 휴대폰의 **터치 리모컨 열기**로 조작합니다.

- **드래그 영역:** 십자·그리드 패드에서 Windows 커서 이동, 탭 클릭, 누른 채 드래그.
- **버튼 영역:** 아이콘과 짧은 이름의 명령 목록. ⋯에서 이름/명령 편집·삭제, 최대 8개 추가·저장.
- 클릭·우클릭·스크롤·음량·음소거·앱 작업 패널 확대/초기화를 지원합니다.
- 창 닫기·대상 변경·취소·연결 종료·기기 중지·유휴 시 드래그를 해제합니다.

서버와 휴대폰·Windows 출력을 함께 업데이트하세요. Linux CLI 서버는 입력을 Windows 클라이언트로 전달합니다. Android 시스템 전체 마우스 제어와 화면 전송은 포함하지 않습니다. Windows는 단일 EXE, Android는 기존 서명 키의 versionCode 10 APK, Linux는 x64 CLI tar.gz입니다.

사용법: [터치 리모컨](../docs/TOUCH.md). 이전 제스처 설정을 켜도 명령은 실행되지 않습니다.
