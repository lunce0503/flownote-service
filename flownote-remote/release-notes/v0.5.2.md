# Flownote Remote 0.5.2 · 골격 오류 후 연결 유지

- Android에서 골격 전송을 켜고 미리보기가 나온 직후 연결이 끊길 수 있던 문제를 수정했습니다. 화면 밖 발 관절 등 범위를 벗어난 골격 프레임만 제외하고 연결·수동 제어·다음 프레임 수신을 유지합니다.
- 거부 시 제스처 유지 판정을 초기화합니다. 잘못된 프레임이 제스처 명령을 실행하거나 앞뒤 유지 시간을 이어 붙이지 않습니다.
- 서버와 클라이언트의 연결 기록에 `landmark_out_of_range` 등의 원인 코드를 남깁니다. 반복 로그는 5초 간격으로 제한하며 영상·좌표·인증값은 기록하지 않습니다.
- 실제 모델의 상체 입력→잘못된 관절→TLS 프레임 거부→정상 제스처/수동 제어 복구 검사를 추가했습니다. Android의 실제 후면 카메라 토글·미리보기와 Windows WebView의 다음 정상 프레임 복구도 검사합니다.

서버와 클라이언트를 모두 업데이트해 주세요. 기존 좌표·크기·스키마·인증 검증은 유지합니다. 프레임이 계속 거부된다면 카메라 구도를 조정하고 `⋯ → 연결 정보와 기록`을 확인하세요. Linux 서버는 stderr에 같은 코드를 표시합니다.

Windows는 단일 EXE, Android는 기존 키의 versionCode 9 APK, Linux는 x64 CLI tar.gz로 제공합니다. 상세 계약은 [네트워크 안내](https://github.com/lunce0503/flownote-remote-service/blob/v0.5.2/docs/NETWORK.md)를 따릅니다.
