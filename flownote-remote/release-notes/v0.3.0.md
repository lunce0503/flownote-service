# Flownote Remote 0.3.0 · 대시보드와 QR 연결

- 앱을 열면 소리·카메라·제스처·음성 알림 카드와 클라이언트 목록이 먼저 표시됩니다. 세부 설정·연결 정보·기록은 화면과 기기의 `⋯` 메뉴에서 확인합니다.
- 클라이언트 행에 사용 토글, 기기 이름, 실제 연결된 기능을 요약합니다. 오프라인·일시 중지·출력 장치 오류를 구별하고, 미구현 기능은 사용 중이라고 표시하지 않습니다.
- 서버는 각 기기의 사용을 허용/중지하고, 클라이언트는 자기 기기를 일시 중지할 수 있습니다. 중지 중에는 카메라와 출력 제어를 차단하면서 상태 연결은 유지합니다. 다시 켜도 카메라는 자동 시작하지 않습니다.
- Windows 서버의 **클라이언트 연결**에서 2분·일회용 QR을 보여 줍니다. Android/Windows의 카메라로 읽거나 **연결 코드 복사/붙여넣기**를 사용합니다. 주소·지문을 직접 입력하는 방법도 세부 화면에 남아 있습니다.
- QR을 읽은 뒤 내 서버인지 확인하고 **확인하고 연결**을 눌러야 등록합니다. QR은 장기 토큰을 포함하지 않으며 만료·재사용·잘못된 지문은 거부합니다. 같은 사설망/VPN에서 사용합니다.

Windows는 항상 단일 EXE이며 .NET·모델·라이선스를 포함합니다. WebView2 Runtime은 PC에 필요합니다. Android APK는 기존 release 키를 유지하고 versionCode 4를 사용합니다. 두 기기에 0.3.0을 함께 설치하면 기기 사용 토글을 모두 사용할 수 있습니다.

음원 스트리밍·분리/합성, 화면·프로젝터 출력, 대화형 AI는 아직 연결 전입니다. 상태 알림은 OS TTS를 사용합니다. 실제 카메라/스피커와 VPN 환경은 별도 실기기 확인이 필요합니다.

자세한 사용법과 계약은 [네트워크 문서](https://github.com/lunce0503/flownote-remote-service/blob/v0.3.0/docs/NETWORK.md)를 확인하세요.
