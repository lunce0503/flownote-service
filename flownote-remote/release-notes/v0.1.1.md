# Flownote Remote 0.1.1 · EXE 배포 시험판

- Windows 배포는 앞으로 항상 `Flownote-Remote-<version>-windows-x64.exe` 단일 파일로 제공합니다. ZIP 압축 해제나 .NET 별도 설치 없이 EXE를 내려받아 실행하세요.
- Sound Manager와 .NET 라이선스를 EXE에 포함하고 앱의 **오픈소스 라이선스**에서 읽을 수 있게 했습니다.
- 배포할 EXE 한 파일만 있는 빈 폴더에서 실행·라이선스 표시·설정 저장·재시작 복원을 검증합니다.
- Android는 같은 release 키로 서명한 0.1.1/versionCode 2입니다. 기존 0.1.0 release 앱 위에 업데이트할 수 있습니다.

설정·제스처 합성 입력 시험판입니다. 실제 카메라 인식, 시스템 음량/오디오 출력, 비서 실행, 기기 간 연결은 아직 제공하지 않습니다. Windows 설치 프로그램·자동 업데이트·Authenticode 서명은 없습니다.

다운로드 파일은 Windows EXE, Android APK, `SHA256SUMS.txt`입니다. 체크섬을 확인하려면 PowerShell에서 `Get-FileHash <파일> -Algorithm SHA256`을 사용하세요.
