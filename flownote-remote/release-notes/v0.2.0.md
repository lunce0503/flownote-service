# Flownote Remote 0.2.0 · 서버/클라이언트 시험판

- Windows PC 서버와 Android·Windows 입출력 클라이언트를 연결합니다. 사설망/VPN의 HTTPS/WSS와 일회용 등록 코드·인증서 지문으로 기기를 등록합니다.
- 서버에서 카메라 JPEG를 실제 MediaPipe 모델로 판정해 선택한 클라이언트의 OS 음량·음소거를 제어합니다. 카메라는 사용자가 시작하며 제스처 명령 허용은 서버에서 기본 OFF입니다.
- 클라이언트 수동 제어, 상태 확인, 기기 등록 해제, 연결 끊김·배터리 부족·Windows 메모리 압박·출력/분석 오류의 화면 및 OS 음성 알림을 제공합니다.
- Windows는 단일 EXE, Android는 같은 release 키의 0.2.0/versionCode 3 APK입니다. Windows 카메라 인식에는 WebView2 Runtime이 필요하며 없으면 기능 준비 실패를 표시합니다. .NET·모델·라이선스는 EXE에 포함합니다.

## 연결 순서

1. Windows 앱의 **서버 · 클라이언트 연결**에서 같은 네트워크의 PC IPv4를 골라 서버를 시작합니다.
2. 클라이언트에 서버 주소·SHA-256 지문·2분짜리 등록 코드를 입력하고 지문을 대조합니다.
3. 서버에서 제어 대상·음성 출력 기기를 고르고, 클라이언트에서 카메라 전송을 시작합니다.
4. 서버에서 카메라 제스처 명령 허용과 현재 설정 적용을 선택합니다. 기본 80% 미만의 판정은 실행하지 않습니다. 상태 창의 실제 신뢰도를 보고 필요할 때 설정을 조정하세요.

원본 카메라 영상을 파일로 저장하지 않습니다. Windows 방화벽은 신뢰하는 사설 네트워크에만 허용하세요. 포트 자동 개방·공개 인터넷 연결은 없고 다른 네트워크에서는 기존 사설 VPN을 사용합니다.

음원 전송·stem 분리·합성 출력, 화면 배치·화면 전송·프로젝터, 대화형 AI 비서는 아직 연결 전입니다. 상태 알림은 실제 지표의 규칙과 OS TTS를 사용합니다. 음성 엔진·스피커가 없거나 음소거면 화면 알림을 유지합니다. 이 시험판은 안전 보장 시스템이 아닙니다.

Windows EXE·Android APK·SHA256SUMS.txt를 제공합니다. 설치 프로그램·자동 업데이트·Windows Authenticode 서명은 없습니다. 자세한 계약과 제한은 [네트워크 문서](https://github.com/lunce0503/flownote-remote-service/blob/v0.2.0/docs/NETWORK.md)를 확인하세요.
