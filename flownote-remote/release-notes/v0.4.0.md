# Flownote Remote 0.4.0 · Linux CLI와 Codex 음성

- Linux x64 CLI: 기존 Android/Windows 앱과 연결하는 사설/VPN HTTPS/WSS 서버, 단기 연결 링크, 기기 목록/권한/대상/제스처/미디어 관리.
- 실제 로컬 Chromium/MediaPipe 인식. 모델 없이 관리만 실행하는 `--no-vision` 모드. Linux 사용자 전용 상태/소유자 소켓과 재시작 후 등록 유지.
- Codex 자체 TUI를 여는 `voice --native`와 실험적 실시간 PCM 음성 브리지. ALSA 장치 또는 SSH 표준 입출력 지원. 선택적 제한된 미디어 도구.
- Windows는 계속 단일 EXE, Android는 기존 키로 서명한 APK. Linux는 .NET 포함 tar.gz이며 제스처 사용에는 Node.js 24와 Playwright Chromium/OS 의존성 설치가 필요하다.

**음성 검증 제한:** 실제 Codex 0.164.0에서 로그인·규약 연결은 확인했지만 현재 계정의 WebSocket 음성은 `realtime conversation requires API key auth`로 거부됐다. 음성 브리지는 지원 API 인증·음성 모델 권한이 필요하다. 네이티브 `/voice` 사용 가능 여부는 Codex 버전/계정/장치에 따른다. 오프라인 PCM 검사를 실제 음성 대화 성공으로 표시하지 않는다. Android/Windows 앱 마이크 연결은 후속이다.

연결·설치·명령·제한은 [CLI 안내](../docs/CLI.md)와 [네트워크 명세](../docs/NETWORK.md)를 따른다. 기존 Windows WebView2 필요 조건과 음원 분리/합성·화면/프로젝터 기능 미구현 범위는 유지한다.
