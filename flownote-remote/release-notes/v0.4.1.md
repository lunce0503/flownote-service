# Flownote Remote 0.4.1 · Codex 로그인 계정 음성

- 기본 `voice`를 Codex CLI의 로그인된 ChatGPT 계정과 WebRTC로 연결한다. API 키가 필요하지 않으며 API 키 인증으로 자동 대체하지 않는다.
- Codex가 계정 인증·토큰 갱신·호출 생성을 담당한다. Flownote는 인증 파일/토큰을 읽거나 복사하지 않는다. API 키 환경 변수를 Codex 음성 프로세스와 미디어 worker에 전달하지 않는다.
- 실제 세션 시작과 WebRTC 연결을 확인한 뒤 마이크를 열고, 오디오는 ALSA 또는 SSH PCM 파이프로 주고받는다. Node.js 24와 포함된 Playwright 버전의 Chromium/OS 의존성이 필요하다.
- 실제 로그인 계정으로 세션 연결과 무음이 아닌 음성 응답 수신을 확인했다. 별도 Chromium 양단 검사로 AudioWorklet/WebRTC/Opus/PCM 경로를 검증한다. 물리 마이크/스피커와 원거리 SSH 지연은 별도 장치 검증이다.
- `voice --native`와 제한된 미디어 MCP, 기존 Linux 서버, Windows 단일 EXE·동일 키의 Android APK 정책을 유지한다.

0.4.0에서의 API 키 오류는 기존 WebSocket 음성 전송 경로 때문이었다. 로그인 계정의 음성 전체가 API 키를 요구한다는 의미가 아니며 이번 버전에서 해당 경로를 수정했다. 설치·명령은 [CLI 안내](https://github.com/lunce0503/flownote-remote-service/blob/v0.4.1/docs/CLI.md)를 따른다.
