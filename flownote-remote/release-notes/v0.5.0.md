# Flownote Remote 0.5.0 · 범주별 제스처와 골격 전송

이 버전은 게시 전에 중단했습니다. 음량 정밀 입력을 보완한 공개 버전은 [0.5.1](v0.5.1.md)입니다.

- 전체 / 중간 관리 / 세밀 조정의 11개 제스처를 제공합니다. 양팔 펼치기→전체 앱 최소화, 손목 올리기→복원, 손목 교차→전체 음소거, 펼쳤다 쥐기→작업 선택, 좌우 이동→이전/다음 작업, V→상세 보기를 추가했습니다.
- 정확한 값은 키보드로 입력합니다. 핀치 모드를 직접 켜면 음량·확대축소·위치를 미세 조정할 수 있습니다. Esc나 카메라 중지로 해제합니다.
- 카메라 선택에서 후면을 지정하고 저장할 수 있습니다. Windows는 물리 장치 선택도 지원합니다. 후면/선택 장치가 없으면 안내하고 다른 카메라로 자동 전환하지 않습니다.
- 클라이언트가 손 21점과 자세 33점의 뼈대를 추출해 미리보기에 표시하고 관절 데이터만 서버로 보냅니다. 기존 사진 전송은 차단합니다. 서버와 클라이언트를 함께 업데이트해 주세요.
- Linux 서버는 골격 판정을 위해 Node/Chromium이 필요하지 않습니다. Codex 계정 음성에는 기존 Node/Chromium이 필요합니다. 실제 연결된 음성 세션은 같은 사용자의 서버 작업 목록에 자동 등록·제거합니다.

전체 화면 제어는 Flownote Remote 앱에, 확대·이동은 선택한 작업 패널에 적용됩니다. Android 최소화는 카메라와 연결을 중지하므로 사용자가 앱을 다시 열어 재연결해야 합니다. 임의 에이전트 종료·다른 앱 창 조작은 포함하지 않습니다.

Windows는 단일 EXE, Android는 기존 키의 versionCode 7 APK, Linux는 x64 tar.gz이며 체크섬을 함께 배포합니다. 상세 동작·데이터·검증 범위는 [제스처 안내](https://github.com/lunce0503/flownote-remote-service/blob/v0.5.0/docs/GESTURES.md)를 따릅니다. 물리 카메라/조명별 인식 품질은 실기기 확인이 필요합니다.
