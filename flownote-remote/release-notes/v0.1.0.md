# Flownote Remote 0.1.0 · 초기 설정 시험판

Android·Windows용 소리/제스처 원격 앱의 첫 시험 릴리스입니다.

- 카메라 방향, 제스처별 동작, 신뢰도·유지 시간·재실행 간격 설정과 기기별 저장/복원.
- 합성 제스처 입력으로 실행 후보 이름 확인.
- 음량·EQ 설정. Windows는 Sound Manager DSP 코어에 내부 설정을 적용합니다.

**카메라 프리뷰·실제 제스처 인식, 시스템 음량/실제 오디오 출력, 비서 실행, 기기 간 연결은 아직 제공하지 않습니다.** 제스처는 기본 OFF입니다. 카메라 권한은 요청하지 않으며 마이크·인터넷 권한도 없습니다.

## 다운로드와 실행

- Android 10 이상: `Flownote-Remote-0.1.0-android.apk` 설치. 별도 release 키로 서명했으며 기존 Flownote/원격 터미널과 다른 패키지입니다. 이전 개발용 staging APK와는 별도로 설치됩니다.
- Windows x64: `Flownote-Remote-0.1.0-windows-x64.zip`을 모두 풀고 `Flownote.Remote.exe`를 실행하세요. .NET 런타임이 포함되어 별도 설치가 필요 없습니다. 설치 프로그램·자동 업데이트·Authenticode 서명은 없는 portable 시험판입니다.
- `SHA256SUMS.txt`로 다운로드 무결성을 확인할 수 있습니다. Windows PowerShell의 `Get-FileHash <파일> -Algorithm SHA256` 또는 Linux의 `sha256sum -c SHA256SUMS.txt`를 사용하세요.

GitHub Actions에서 Android 단위/lint/release 빌드·APK 서명 확인·Android 10 에뮬레이터 설치/실행과 Windows self-contained 패키지 실행·설정 저장/재시작 복원을 통과한 동일 파일만 게시합니다. 실제 카메라·Bluetooth·기기 간 네트워크 검증은 후속 기능 구현 뒤 수행합니다.
