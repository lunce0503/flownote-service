# 휴대폰 터치 리모컨 (0.6.0)

제스처 입력을 중지하고 Android 휴대폰의 터치 입력으로 전환한다. 서버는 저장된 `gesturesEnabled=true`와 설정 변경을 무시해 항상 OFF를 유지하며 CLI `gestures on`도 거부한다. 호환 진단용 골격 프레임은 검증하고 응답하지만 명령을 생성하지 않는다. QR 스캔은 연결 도구로 유지한다.

## 사용 흐름

1. Windows PC 또는 Linux CLI에서 서버를 시작하고 기존 QR/코드로 휴대폰을 연결한다. Windows PC 서버는 ‘이 PC’ 출력 클라이언트를 자동 연결한다. Linux 서버는 Windows 출력 클라이언트를 따로 연결한다.
2. Windows의 **휴대폰 마우스 제어 허용**을 확인한다. 서버에 인증된 사용 중인 기기에만 적용되며 이 체크를 끄거나 기기 사용을 중지할 수 있다.
3. 휴대폰에서 **터치 리모컨 열기**를 누르면 입력창이 나타난다. 대상 기기는 창 위의 목록에서 선택한다. 처음에는 마우스 가능 기기를 선택하며 소리만 가능한 기기도 버튼 대상으로 선택할 수 있다.
4. **드래그 영역**은 십자축과 그리드, 위치 표식을 표시한다. 손가락 이동은 상대 커서 이동이며 탭은 왼쪽 클릭이다. **누른 채 드래그**를 켠 뒤 손을 대면 마우스 왼쪽 버튼을 누르고, 움직이는 동안 끌고, 떼거나 취소하면 놓는다. 두 번째 손가락이 닿으면 입력을 취소한다. 스크롤은 버튼 명령으로 제공한다.
5. **버튼 영역**은 아이콘과 짧은 이름의 세로 목록이다. 기본값은 클릭·우클릭·음량 높이기/줄이기·음소거·배치 초기화다. 각 행 ⋯에서 이름(1–20자)과 명령 변경 또는 삭제, 아래 **커스텀 버튼 추가**에서 최대 8개를 저장한다. 선택 명령은 클릭/우클릭/위·아래 스크롤/음량/음소거·해제/앱 패널 확대·축소/배치 초기화로 제한한다. 설정은 이 휴대폰에 남으며 이름은 실행 코드로 사용하지 않는다.

작은 화면과 큰 글꼴에서는 창 전체를 세로 스크롤한다. 패드 위에서 움직일 때는 부모 스크롤을 막는다. 표준 버튼·스위치·Spinner와 패드의 접근성 클릭을 제공한다. 이 입력창은 카메라/핀치를 사용하지 않는다.

## 제어 범위와 실패 처리

- 커서·클릭·드래그·스크롤은 Windows 데스크톱 마우스 입력이다. Windows SendInput의 권한 경계 안에서 작동하며 관리자 앱/보안 데스크톱 권한을 올리거나 우회하지 않는다. [Microsoft MOUSEINPUT](https://learn.microsoft.com/en-us/windows/win32/api/winuser/ns-winuser-mouseinput)의 상대 이동/버튼 규약을 따른다.
- 확대·축소·배치 초기화는 기존 Flownote Remote 작업 패널에 적용한다. 일반 앱 확대나 화면 스트리밍을 뜻하지 않는다. 음량 명령은 선택 기기의 실제 출력이다. Android 출력은 소리/작업 패널을 지원하며 시스템 전체 마우스 주입은 광고하지 않는다.
- 연결 전·연결 끊김·기기 일시 중지·구버전 서버에서는 입력을 비활성화하고 상태를 표시한다. 대상 변경·입력창 닫기·백그라운드 전환·터치 취소는 이전 대상의 드래그를 놓는다. 연결 복구 뒤 눌린 상태를 복원하지 않는다.
- 드래그는 한 대상당 한 휴대폰이 소유한다. 클라이언트는 400ms마다 hold를 보내고 서버는 소유자 종료/사용 중지/유휴 시 해제한다. Windows는 별도 250ms 감시로 마지막 정상 입력 후 1.5초 넘으면 직접 버튼을 놓는다.
- 이동 전송은 약 30Hz, 한 번의 x/y 상대 이동은 각각 ±128, 스크롤은 ±3 노치다. 서버는 소스별 초당 60개와 응답 대기량을 제한하며 과부하는 연결 종료 없이 거부한다. 마우스 이동마다 전체 상태를 재방송하거나 로그를 만들지 않는다. 출력 실패 로그는 최대 5초에 한 번이다.

메시지와 TLS/사용 권한 경계는 [NETWORK.md](NETWORK.md)를 따른다. Windows 단일 EXE와 APK 서명 정책은 [RELEASING.md](RELEASING.md)를 유지한다. 클라우드 웹/API 실행 산출물은 없다.

## 검증

- Network.Checks: 실제 pinned TLS/WSS에서 이동/클릭/드래그, 소유자 경쟁, 소스·대상 pause, 소스 종료·유휴 해제, 역량·범위·명령 검증, 제스처 활성화 차단.
- Windows.Checks: 실제 SendInput으로 테스트 창의 이동/클릭/우클릭/wheel/드래그와 로컬 OFF·독립 유휴 해제. 관리자 앱과 물리 기기는 별도 수용 범위다.
- Android: 단위/lint/build, 실제 Android 10 MotionEvent 탭/이동/취소/hold, 기본 입력창을 통한 실제 TLS 출력 도달, 버튼 편집/저장, 320dp/font scale 1.3 캡처.
