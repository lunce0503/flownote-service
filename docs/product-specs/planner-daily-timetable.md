# 플래너 일간 시간표

## 목표

오늘의 전체 24시간을 빠짐없이 보고 할일 색상을 5분 단위로 칠하며, 마지막 칠하기 동작을 한 번에 되돌릴 수 있게 한다.

## 사용자 흐름

1. 플래너 일간 탭의 시간표는 `00:00`부터 `23:00`까지 시간축을 표시한다.
2. 할일을 선택하고 시간표를 누르거나 드래그하면 각 칸을 5분 단위로 칠한다.
3. 지우개를 선택하면 같은 5분 단위로 칠한 칸을 지운다.
4. `칠하기 되돌리기`는 마지막 포인터 누름부터 놓기까지 변경한 칸 전체를 복구한다.
5. 되돌릴 칠하기 동작이 없으면 버튼을 비활성화한다.

펜 입력과 펜 되돌리기·필기 전체 삭제 컨트롤은 제공하지 않는다. 이전 버전에서 저장한 필기 획은 데이터 손실을 피하기 위해 읽기 전용으로 렌더링한다.

## 데이터와 호환성

- 현재 격자는 `startHour: 0`, `endHour: 24`, `cols: 12`를 사용한다. 한 행은 한 시간이고 열 한 칸은 5분이다.
- 과거 `startHour: 6`, `endHour: 24`, `cols: 6` 데이터는 로드 시 시간 위치를 보존해 새 격자로 변환한다.
- 과거 10분 칠하기 한 칸은 연속된 5분 칸 두 개로 변환해 칠한 지속시간을 보존한다.
- 과거 필기 획의 세로 정규화 좌표는 원래 시각이 유지되도록 24시간 축으로 변환한다.
- 칠하기 undo 이력은 현재 선택한 날짜의 메모리에만 유지하며 날짜를 바꾸거나 다시 로드하면 초기화한다.

## 저장과 오류 상태

- 칠하기, 지우기, 되돌리기는 기존 일기 자동 저장 debounce를 사용한다.
- 서버 저장 실패는 플래너 상단 저장 상태의 `저장 실패`로 표시한다.
- 되돌리기는 서버 요청 완료 여부와 관계없이 현재 화면의 마지막 칠하기 동작을 즉시 복구한다.

## 검증

- 캔버스 높이와 시간 라벨이 24개 시간 행을 나타낸다.
- 저장 payload의 격자 설정이 `0/24/12`이고 첫 번째 칸은 `00:00~00:05`를 뜻한다.
- 한 번의 드래그로 여러 칸을 칠한 뒤 undo하면 해당 동작의 칸이 모두 원복된다.
- 펜, 펜 되돌리기, 필기 전체 삭제 버튼이 노출되지 않는다.
- 390px 모바일 화면에서 시간표와 undo 버튼이 가로로 넘치지 않는다.
