# 캔버스 PDF 책 읽기

데스크톱 툴바의 `PDF 책 읽기`, 모바일 `파일 동작 → PDF 책 읽기`로 연다. 기존 페이지 이미지 가져오기와 별개이며, PDF 한 페이지씩 앞뒤로 넘기면서 캔버스에 계속 필기할 수 있다.

- 데스크톱·짧은 모바일 가로 화면은 좌우, 모바일 세로 화면은 상하 분할한다. PDF는 터치로 스크롤하고 캔버스 입력과 분리한다.
- PDF 선택 후 이전/다음 버튼이나 방향키로 넘긴다. 렌더 중/첫끝 페이지에서도 버튼의 키보드 포커스를 유지하고 캔버스 도구·실행 취소 단축키로 전파하지 않는다. Escape/닫기는 트리거에 포커스를 돌려준다.
- PDF는 현재 기기 메모리에만 열고 외부 업로드·캔버스 저장·OCR을 하지 않는다. 닫거나 캔버스를 바꾸거나 새로고침하면 파일을 다시 선택한다. 기존 선·텍스트·이미지를 변경하지 않는다.
- 빈 파일·비PDF·50MB 초과는 거부한다. 암호화/손상/렌더 실패는 오류로 안내하고 다른 파일을 선택할 수 있다. 한 페이지 최대 변 1600px로 렌더 메모리를 제한하고 worker/document/render 작업은 교체·닫기 시 정리한다. PDF.js eval은 비활성화한다.

검증: `canvasPdfReader.test.mjs`, `e2e-cloud/canvas-pdf-reader.spec.ts`(실제 staging, 연속 키보드 이동·포커스·기존 문서 보존·독립 필기·파일 교체·390px 세로/844×390 가로·실제 터치 스크롤).
