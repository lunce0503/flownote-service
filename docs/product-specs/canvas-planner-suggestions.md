# 캔버스 플래너 제안

## 사용자 흐름

캔버스의 `플래너 제안`을 열면 현재 텍스트 박스에서 작업과 일정 후보를 자동으로 만든다. 모바일에서는 `파일 동작` 메뉴로 접근한다. 삭제된 텍스트와 완료 체크박스는 제외하고 동일한 후보는 한 번만 표시하며 최대 30개를 제안한다.

날짜 `YYYY-MM-DD`와 오늘·내일·모레, 시간 구간 `14:00~15:00`을 인식한다. 날짜가 없으면 오늘을 제안하고 유효한 시간 구간이 있으면 일정, 나머지는 작업으로 제안한다. 잘못된 날짜나 역순 시간은 일정으로 해석하지 않는다. 후보는 사용자가 제목·종류·날짜·시간을 확인하고 수정할 수 있다.

`플래너에 추가`를 눌러야 저장한다. 작업은 기존 `/api/tasks`에 마감일과 함께 생성하고 일정은 해당 날짜의 일간 시간표에 할 일과 5분 단위 칸으로 저장한다. 기존 칸과 겹치는 일정은 오류로 안내하며 기존 할 일·일기·필기·시간표를 지우지 않는다. 저장 중에는 중복 제출과 편집을 막고 성공한 후보는 `추가됨`으로 표시한다.

텍스트 분석은 브라우저의 규칙 기반 처리이며 외부 AI에 내용을 보내지 않는다. 손글씨·이미지·PDF OCR은 포함하지 않는다. 여러 기기의 동시 diary 수정은 기존 전체 문서 저장 계약을 따르므로 이 기능이 별도의 충돌 버전을 제공하지는 않는다.

## 검증

- `node --test flownote/src/features/planner/model/canvasPlannerSuggestions.test.mjs`: 날짜·시간 추출, 완료·삭제 제외, 후보 중복 제거, 잘못된 입력, 기존 내용 보존과 시간 겹침 거부.
- `flownote/`의 `yarn build`: 타입과 프로덕션 번들.
- `e2e-cloud/feedback-implementation.spec.ts`: 실제 스테이징 캔버스에서 작업·일정 생성, 기존 일기 보존, 모바일 접근과 원형 버튼 확인.
