# 웹 작업 공간 UX

## 목표

Flownote 웹의 첫 화면과 핵심 편집 흐름은 실제 동작만 노출하고, 네트워크 실패·빈 데이터·저장 진행 상태를 사용자가 구분할 수 있어야 한다. 모바일에서도 제목 편집과 Canvas 파일 동작에 별도 탐색 없이 접근할 수 있어야 한다.

## 홈과 인증

- 홈은 게시글, 플래너, AI 에이전트, Canvas로 이동하는 실제 링크를 제공한다.
- 홈 검색은 기능 이름·설명·관련 키워드로 바로가기를 필터링한다. 사용자 데이터처럼 보이는 고정 통계나 최근 항목은 표시하지 않는다.
- 회원가입은 `POST /api/users`가 성공한 뒤에만 로그인 화면으로 이동한다.
- 회원가입 실패는 폼에 오류 메시지를 표시하고 입력 화면에 머문다.
- 비밀번호 재설정과 소셜 로그인처럼 구현되지 않은 동작은 로그인 화면에 활성 컨트롤로 노출하지 않는다.

## Blog 상태와 자동 저장

- 노트 API 설정 누락이나 요청 실패는 빈 배열로 바꾸지 않고 호출 화면에 전달한다.
- Blog 목록은 로딩, 빈 목록, 조회 오류를 서로 다른 상태로 표시하며 오류 상태에서 다시 시도할 수 있다.
- 노트 편집기는 변경됨, 저장 중, 재시도 중, 저장됨, 저장 실패 상태를 `aria-live` 영역에 표시한다.
- 자동 저장 실패는 최초 요청 뒤 500ms, 1초, 2초 간격으로 최대 3회 재시도하고 종료한다.
- 재시도가 끝나면 사용자는 저장을 다시 시도하거나 서버에 저장된 버전으로 변경을 취소할 수 있다.
- 저장 실패 뒤 새 입력이 발생하면 이전 대기 스냅샷 대신 가장 최신 문서를 저장 대상으로 사용하고 재시도 횟수를 초기화한다.
- 화면을 떠날 때 예약된 재시도 타이머를 제거해 백그라운드 요청을 지속하지 않는다.

## 모바일 편집

- 노트 제목 입력은 모바일에서 한 행 전체를 사용하며 드로잉·전체 화면 동작은 별도 행에 배치한다.
- Canvas 모바일 도구막대는 탐색·제목·저장 상태·파일 메뉴를 첫 행에, 그리기 도구와 색상을 다음 행에 둔다.
- Canvas 저장, 불러오기, 전체 화면, 설정은 `파일 동작` 메뉴에서 이름과 아이콘으로 제공한다.

## 키보드와 모달

- 헤더 메뉴는 열릴 때 첫 항목에 포커스를 두고 방향키, Home, End로 항목을 이동한다.
- Escape로 헤더 메뉴와 사이드바를 닫으면 해당 트리거로 포커스를 돌려보낸다.
- 드로잉 필기는 대화상자로 노출하고 포커스를 내부에 유지하며, 저장 중이 아닐 때 Escape로 닫을 수 있다.
- 아이콘만 있는 닫기 버튼은 접근 가능한 이름을 제공한다.

## 검증

- `cd flownote && yarn lint && yarn build`
- 공식 Playwright 컨테이너에서 `yarn e2e`
- 390px 모바일, 820px 태블릿, 1440px 데스크톱 화면에서 가로 overflow와 주요 컨트롤 가시성 확인
