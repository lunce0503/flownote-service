# 웹 작업 공간 UX

## 목표

Flownote 웹의 첫 화면과 핵심 편집 흐름은 실제 동작만 노출하고, 네트워크 실패·빈 데이터·저장 진행 상태를 사용자가 구분할 수 있어야 한다. 모바일에서도 제목 편집과 Canvas 파일 동작에 별도 탐색 없이 접근할 수 있어야 한다.

## 홈과 인증

- 홈은 노트·캔버스 통합 작업 공간, 책장, 플래너, AI 에이전트로 이동하는 실제 링크를 제공한다.
- 홈 검색은 기능 이름·설명·관련 키워드로 바로가기를 필터링한다. 사용자 데이터처럼 보이는 고정 통계나 최근 항목은 표시하지 않는다.
- 회원가입은 `POST /api/users`가 성공한 뒤에만 로그인 화면으로 이동한다.
- 회원가입 실패는 폼에 오류 메시지를 표시하고 입력 화면에 머문다.
- 비밀번호 재설정과 소셜 로그인처럼 구현되지 않은 동작은 로그인 화면에 활성 컨트롤로 노출하지 않는다.
- 설정의 내 프로필에서 사용자 이름·표시 이름·이메일을 수정한다. 이메일 변경에는 현재 비밀번호가 필요하며, `PATCH /api/users/me`는 인증 세션의 본인만 변경한다. 저장된 프로필은 로그인 상태와 로컬 캐시에 즉시 반영한다.

## 설정과 보기 편의

설정 화면은 데스크톱에서 최대 1440px로 넓히고 모바일에서는 가용 폭에 맞춘다. 글자 크기·줄 간격·움직임 줄이기는 앱 시작 시 복원하고 같은 기기의 다른 탭에도 동기화한다. 보기 설정 초기화는 프로필이나 사용자 문서를 바꾸지 않는다. 공통 삭제 확인 스위치는 실제 삭제 흐름과 연결되지 않아 제거하며 각 기능의 기존 동작은 변경하지 않는다. 움직임 줄이기는 캔버스 관성도 끈다.

## 노트 상태와 자동 저장

- 노트 API 설정 누락이나 요청 실패는 빈 배열로 바꾸지 않고 호출 화면에 전달한다.
- 노트 목록은 로딩, 빈 목록, 조회 오류를 서로 다른 상태로 표시하며 오류 상태에서 다시 시도할 수 있다.
- 노트 Markdown 작업 공간은 변경됨, 기기에 보관됨, 저장 중, 서버에 저장됨, 실패·복구/충돌 확인 필요를 구분해 status 영역에 표시한다. legacy 원본은 명시적 전환 전 자동 저장하지 않는다. [상세 제품 기준](blog-markdown-workspace.md)을 따른다.
- 자동 저장 실패는 최초 요청 뒤 500ms, 1초, 2초 간격으로 최대 3회 재시도하고 종료한다.
- 재시도가 끝나면 사용자는 저장을 다시 시도하거나 서버에 저장된 버전으로 변경을 취소할 수 있다.
- 저장 실패 뒤 새 입력이 발생하면 이전 대기 스냅샷 대신 가장 최신 문서를 저장 대상으로 사용하고 재시도 횟수를 초기화한다.
- 화면을 떠날 때 예약된 재시도 타이머를 제거해 백그라운드 요청을 지속하지 않는다.

## 모바일 편집

- 노트 제목과 저장 상태는 모바일에서 줄바꿈하고 편집·미리보기·내보내기는 별도 행에 둔다. 탐색기는 닫을 수 있는 drawer이며 원본 그리기는 JSON 보기/내보내기로 보존한다.
- Canvas 모바일 도구막대는 탐색·제목·저장 상태·파일 메뉴를 첫 행에 둔다. 도구 행에는 되돌리기, 현재 도구 아이콘, 펼치기 버튼만 표시하고 펼친 목록에서 도구와 이미지 추가를 선택한다.
- Canvas 저장, 불러오기, 설정은 `파일 동작` 메뉴에서 이름과 아이콘으로 제공한다.
- Canvas 목록 버튼은 다른 도구처럼 흰 배경의 원형 버튼을 사용한다. 데스크톱의 `플래너 제안` 버튼과 모바일 `파일 동작 → 플래너 제안`에서 텍스트 후보를 확인한다. 자세한 제안·추가 기준은 [캔버스 플래너 제안](canvas-planner-suggestions.md)을 따른다.
- Canvas에서 펜슬 전용 그리기가 켜져 있으면 한 손가락은 콘텐츠를 그리지 않고 화면을 이동한다. 처음 움직인 주 방향이 가로면 X축, 세로면 Y축으로 제스처가 끝날 때까지 고정한다.
- 두 손가락은 축을 고정하지 않고 화면 이동과 핀치 확대·축소를 함께 수행한다.
- 빠른 이동(0.5 viewport px/ms 이상)은 손을 뗀 뒤 최대 320ms 감속한다. 느린/멈춘 이동과 핀치는 관성을 적용하지 않는다. 축 잠금은 관성에도 유지하며 새 입력·휠·키보드·마우스 이탈·포인터 취소·탭 숨김·도구 변경에서 즉시 정지한다. 터치의 정상적인 implicit leave는 관성을 취소하지 않는다.
- [PDF 책 읽기](canvas-pdf-reader.md)는 편집 캔버스와 분할 표시한다. 짧은 가로 화면은 좌우 분할하며 실제 헤더와 visual viewport를 기준으로 남은 높이를 사용한다.

## 브라우저 문서 제목

- 브라우저 탭 제목은 제품명으로 고정하지 않고 `기능명-문서 제목` 또는 `기능명-날짜` 형식을 사용한다.
- 노트 상세는 입력 중인 노트 제목을 즉시 반영하고 Canvas 상세는 문서 목록에서 조회한 캔버스 제목을 반영한다.
- 플래너는 현재 선택한 날짜를 `플래너-YYYY-MM-DD` 형식으로 반영한다.
- 문서 맥락이 없는 목록·설정 화면은 `기능명-목록`, `기능명-계정`처럼 화면 역할을 붙인다.

## 키보드와 모달

- 헤더 메뉴는 열릴 때 첫 항목에 포커스를 두고 방향키, Home, End로 항목을 이동한다.
- Escape로 헤더 메뉴와 사이드바를 닫으면 해당 트리거로 포커스를 돌려보낸다.
- 드로잉 필기는 대화상자로 노출하고 포커스를 내부에 유지하며, 저장 중이 아닐 때 Escape로 닫을 수 있다.
- 아이콘만 있는 닫기 버튼은 접근 가능한 이름을 제공한다.

## 검증

- `cd flownote && yarn lint && yarn build`
- 공식 Playwright 컨테이너에서 `yarn e2e`
- 390px 모바일, 820px 태블릿, 1440px 데스크톱 화면에서 가로 overflow와 주요 컨트롤 가시성 확인


## 캔버스·노트 공통 디자인 (2026-10-20)

- 사용자 기능명은 캔버스와 노트로 통일하며 메뉴·문서 제목·파일 동작에 같은 명칭을 쓴다. 기존 URL과 데이터 ID는 유지한다.
- 흰 문서, 베이지 사이드바/선택 영역, 검정 글자/핵심 동작의 공용 색상 변수를 사용한다. 저장한 테마는 유지하며 기본은 밝은 모드, 다크 모드는 따뜻한 검정/베이지다.
- 캔버스 라이브러리는 왼쪽 폴더 트리, 오른쪽 파일 상세 목록이다. 최근 항목·모든 파일·미분류를 전환하고 폴더를 선택해 내용을 본다. 노트와 캔버스를 같은 표에서 검색하고 종류/최근 수정순/이름순으로 필터·정렬한다. 기존 도메인의 폴더 ID와 구성원은 보존한다. 카드 그리드는 사용하지 않는다.
- 이름 변경·이동·삭제는 키보드/터치에서도 가능하다. 폴더 삭제 시 캔버스를 유지한다. 700px 이하에서는 탐색기를 접고 날짜·유형 열을 줄인다.
- [기능 설계·검증 경로](../design-docs/canvas/workspace-explorer-design.md)를 따른다.


2026-10-26 구현 갱신의 배포 상태는 [실행 계획](../exec-plan/active/2026-10-26-workspace-library-ux.md)을 따른다. `/blog`·`/canvas`는 동일 목록이며 상세 URL은 유지한다. 도구막대/파일 메뉴의 전체 화면 버튼을 제거한다. 저장 대기·진행은 배경 없는 회색 저장 중 형태, 완료는 단순 회색 체크로 표시한다. Android/iOS 펜 접촉 중 커서를 숨기고 지원 호버는 4px, 지우개는 투명 내부의 32px 원으로 구분한다. 표시 크기 변경으로 지우기 모델·저장 좌표를 바꾸지 않는다.
