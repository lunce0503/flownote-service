# Android 원격 터미널

소유 구현은 `apps/android/`이다. 앱은 등록된 PC의 `remote-host` 프로토콜 v1과 직접 WSS로 통신한다. 기존 Flownote 웹/Expo 클라우드 클라이언트의 API 목적지 규칙과 별개의 명시적 PC 원격 접속 제품이다.

## 사용자 흐름

PC 등록 → 지문 대조 → TLS·토큰 인증 → hello → PTY 생성 → ANSI 출력 및 입력 → 재접속 또는 명시적 종료.

등록 데이터는 PC 이름, WSS endpoint, 토큰과 인증서 지문이다. 최대 32대의 PC를 목록에 저장하고 추가·편집·삭제·선택 연결한다. 토큰을 URL 또는 로그에 포함하지 않는다. Android Keystore AES-GCM으로 목록과 PC별 세션 ID를 암호화해 앱 전용 저장소에 보관하며 백업과 캡처를 금지한다. 기존 단일 PC/세션은 같은 키로 읽어 목록에 원자적으로 이전한다.

QR 등록은 Host 0.3.0의 `remote-host pair`가 만든 5분 유효·1회용 코드를 카메라로 읽는다. 영구 토큰은 QR에 포함하지 않는다. 스캔 후 주소·지문을 표시하고 사용자 확인을 받은 다음 TLS pinning으로 `/v1/pair`에서 신규 기기 토큰을 받아 저장한다. 수동/JSON 등록은 계속 지원한다. 카메라 거절·취소·잘못된 QR은 저장된 목록을 변경하지 않는다. 상세 계약은 [QR pairing](../../protocol/remote-host/pairing.md)이다.

등록 전 이름·중복 주소·저장 한도를 검사해 로컬 입력 오류로 일회용 코드를 소모하지 않는다. 등록 HTTP 요청과 TLS 연결 정리는 IO 스레드에서 수행한다. 입력 항목은 스크롤하고 저장·연결 버튼은 키보드 위에 고정한다.

## 코드 작업

Android 0.3.0은 Host 0.4.0의 [Workspace API](../../protocol/remote-host/workspace.md)와 같은 인증서·기기 토큰으로 통신한다. 파일 탐색/폴더 필터/페이지, 8개 파일 탭과 CodeMirror 6 편집기(구문 강조·줄 번호·접기·들여쓰기·검색/바꾸기·줄 이동·undo/redo·자동 줄바꿈)를 제공한다. 작은 화면은 파일 목록과 편집기를 전환하고 720dp 이상에서는 함께 표시한다. 키보드가 열린 협소한 화면은 부가 헤더를 접는다.

터미널과 에디터 WebView는 모드 전환 시 유지하며 숨겨진 뷰는 입력·접근성에서 제외한다. 초안은 ViewModel 메모리와 JS 탭 상태에 유지하지만 앱 프로세스 강제 종료 후 디스크 초안 복원은 제공하지 않는다. PC를 떠나거나 미저장 파일을 닫거나 새로 불러오면 버리기 확인을 요구한다. 저장 직전 JS snapshot을 확인하고 revision 충돌 시 자동 재전송·덮어쓰기 없이 초안을 유지한다. 저장 도중 새 입력이 있으면 저장된 snapshot만 base로 갱신해 이후 입력은 dirty로 남긴다. 다른 PC의 epoch에는 이전 undo를 넘기지 않는다. 토큰은 JS에 전달하지 않는다.

파일 루트는 Host의 cwd이며 상대 경로·일반 UTF-8 파일 256KiB 제한을 적용한다. 링크·일반 비밀 파일·생성/삭제는 지원하지 않는다. 프로젝트 설정을 돕는 제한이며 기존 전체 셸 권한의 sandbox를 의미하지 않는다. 코드 파일은 텍스트로만 표시하고 HTML/JS를 실행하지 않는다. LSP·디버거는 이번 버전에 포함하지 않는다.

## 경계

- Kotlin/Compose가 인증, 연결 상태와 생명주기를 소유한다. xterm.js는 앱에 포함된 WebView에서 화면·IME·ANSI만 처리한다.
- 인증서는 등록된 SHA-256 지문, 유효 기간과 호스트명이 모두 일치해야 한다. 자동 재신뢰와 trust-all은 없다.
- WebView 자산은 `appassets.androidplatform.net`의 고정된 출처로 제공한다. 브리지는 메인 프레임과 출처를 확인한다. 외부 탐색·리소스·클립보드 자동 쓰기를 차단한다.
- 입력 스트림을 재전송하지 않는다. 붙여넣기는 8KiB UTF-8 청크로 순서대로 전송하며 JSON 이스케이프 후 Host 64KiB 제한을 만족한다.
- 앱 메모리의 xterm 상태와 처리 완료 seq를 함께 유지할 때만 재접속한다. 앱 재시작·재생 버퍼 초과 시 새 세션 선택을 요구한다.
- PC를 전환하면 이전 연결을 해제한다. 자격 증명과 기억한 세션은 PC별로 분리하고, 다른 PC로 전송하지 않는다. 이전 PC를 다시 열 때 ANSI 화면이 없으면 복구 불가 안내와 새 세션 선택을 제공한다. PC 삭제는 해당 설정/세션만 지우고 다른 PC는 유지한다. 주소/토큰/지문을 바꾸면 해당 PC의 기억한 세션만 제거한다. 같은 주소의 재등록은 사용자 확인 후 기존 항목을 갱신한다.
- 백그라운드에서는 연결을 해제하며 복귀 시 같은 화면으로 재접속한다. Host는 기존 정책에 따라 최대 5분간 PTY를 유지한다.
- 가로·작은 화면에서는 상태 줄을 줄이고 명령 입력창과 도구를 한 줄에 배치한다. 키보드 전환 중에도 터미널 WebView를 유지한다. 네이티브 명령·제어키 전송이 성공하면 최신 출력 위치로 이동하며, 출력만 수신할 때는 사용자의 스크롤 위치를 강제로 변경하지 않는다.

## 배포와 검증

GitHub Actions `Remote Android`가 Android SDK 35로 APK를 빌드하고 JVM 단위 테스트, Android lint와 에뮬레이터 수용 시험을 실행한다. 태그 `remote-android-v*`의 릴리스는 이 검증을 통과한 동일 소스만 사용한다. 서명 정보는 GitHub Actions secrets에 보관한다. Android 앱에 별도 Railway 서비스는 필요하지 않다.

코드맵·설치·명령은 [`../../apps/android/README.md`](../../apps/android/README.md), Host 경계는 [`remote-host.md`](remote-host.md)를 참조한다. 실제 기기 IME·장시간 사용·PC Codex의 대화형 호환 시험은 자동화된 에뮬레이터 시험과 구분해서 결과를 기록한다.
