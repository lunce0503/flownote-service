# Flownote Remote 모바일 IDE

## 목표와 경계

기존 Android 원격 터미널에 PC 프로젝트 파일 탐색, 여러 파일 탭, 코드 구문 강조·줄 번호·접기·자동 들여쓰기, 찾기/바꾸기·실행 취소/다시 실행, 편집·저장을 추가한다. 터미널과 코드 화면 전환 시 PTY와 미저장 내용을 유지한다. 모바일 IME와 작은 화면을 지원한다. LSP/디버거/PC GUI 원격 제어는 이번 구현의 범위가 아니다.

영향 범위는 `apps/android/`, `apps/host/`, 공유 계약과 제품 문서다. Host의 기존 TLS·기기 토큰으로 파일 API를 인증한다. 프로젝트 루트는 Host 설정의 cwd이며 상대 경로만 허용한다. traversal·symlink·비정규 파일·바이너리·과대 파일·일반 비밀 파일은 거부한다. 읽은 revision과 달라졌으면 저장을 거부하며 자동 재전송하지 않는다. 파일 내용/토큰을 로그에 기록하지 않는다.

## 절차

- [x] 기존 앱·브리지·Host HTTPS/인증·릴리스 경로 확인, 보안/API 계약 검토.
- [ ] Host 파일 API와 경로/크기/인증/충돌 회귀 시험.
- [ ] CodeMirror 기반 번들 에디터와 출처 제한 브리지, 편집 명령/IME/탭 상태.
- [ ] Android 파일 탐색·에디터·터미널 전환 및 미저장 변경 확인.
- [ ] Host/브리지/JVM 검사와 Android 에뮬레이터 전체 검증.
- [ ] 동일 검증 소스의 Host 설치기·서명 APK GitHub 릴리스, 서버 업데이트/무결성 확인.
- [ ] 소유 문서와 릴리스 보고서, 최종 기능별 완료 감사.

## 검증

Host Linux/Windows 검증, 기존 Android 터미널·다중 PC·QR 회귀를 유지한다. 새 시험은 실제 Host 파일을 탐색·편집·저장하고 충돌/권한/경로 거부, 터미널 전환 후 초안 유지, 가로/세로·IME를 확인한다. CodeMirror는 검증된 도메인 라이브러리를 사용하고 외부 CDN 없이 APK에 번들한다. 실제 휴대폰의 IME·성능은 자동화와 구분한다.

배포 산출물은 독립 Android APK와 PC Host 설치기다. Flownote 웹/Expo/Railway API 목적지·DB는 변경하지 않는다. 기존 사용자 변경은 포함하지 않는다.
