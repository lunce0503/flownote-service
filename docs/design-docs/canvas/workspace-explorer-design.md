# 캔버스·노트 작업 공간 디자인

2026-10-20. 적용 범위는 `flownote/` 웹과 이를 사용하는 Android/Windows 웹 래퍼다. API·DB·문서 ID·URL은 유지한다.

- 사용자 명칭은 캔버스 / 노트, 영어 노트 메뉴는 Notes다. `/canvas`, `/blog` URL과 내부 식별자는 호환성을 위해 유지한다. 헤더·설치 앱 메뉴·홈·탭 제목·설정/뒤로가기 문구에 적용한다.
- 공통 색상은 흰 문서 영역, 베이지 탐색 영역/선택 배경, 검은 텍스트/핵심 동작이다. 공용 workspace CSS 변수를 사용하며 노트의 파란 강조와 남색 표면을 제거한다. 명시적 다크 모드는 따뜻한 검정/베이지 계열을 사용한다. 저장된 설정이 없는 웹 방문자의 기본은 밝은 모드다.
- 캔버스 목록은 카드 대신 왼쪽 폴더 트리와 오른쪽 상세 목록이다. 최근 항목/모든 캔버스/미분류, category→folder→canvas 계층, 현재 경로, 파일명·수정일·유형·위치 동작을 제공한다. 작은 화면에서는 열을 줄이고 탐색기를 접는다.
- 기존 생성·이름 변경·폴더 이동·삭제·낙관적 생성 표시를 유지한다. 이동은 drag 외 native select로 제공한다. 폴더 삭제는 확인 후 폴더만 지우며 문서는 미분류에 남는다.
- 행은 선택, Enter로 열기, F2로 이름 변경, Delete로 삭제 확인이 가능하다. 폴더 트리는 방향키/Home/End로 이동하고 좌우 방향키로 접기/펼치기를 제어한다.
- 검증은 기본 yarn verify, bundle 경계 검사, staging 전체 E2E와 신규 폴더 CRUD·명칭·밝은/어두운 팔레트·390/820/1440px 검사를 수행한다. staging 통과 동일 소스를 `node scripts/deploy-cloud.mjs release web`로 운영에 배포한다. 백엔드 실행 산출물은 변경하지 않는다.

작업 공간 높이는 공용 shell offset을 사용한다. 웹의 헤더, 설치 앱의 하단 탐색, 넓은 Windows 앱의 측면 탐색에 맞춰 문서 하단의 불필요한 여백을 줄인다.
