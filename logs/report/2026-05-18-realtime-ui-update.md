# 2026-05-18 실시간 동기화 및 UI 개선 기록

## 범위

- 웹 캔버스에 모바일과 동일한 벡터맵 배경을 자동 적용했다.
- Next 서버에 계정 토큰 기반 SSE 동기화 API를 추가했다.
- 게시글과 캔버스 저장/수정/삭제 후 같은 계정의 다른 브라우저 세션에 갱신 이벤트를 발행하도록 연결했다.
- 헤더 대비를 높이고 한국어/영어 전환 설정을 추가했다.
- 에이전트 대화 화면에서 현재 에이전트 패널과 추천 명령 영역을 숨길 수 있게 했다.
- 작업 화면의 수행 시간 그래프를 오늘 기록 기준의 시간 분배로 바꿨다.

## 검증

- `flownote/`: `yarn build` 성공.
- `flownote-next/`: `yarn build` 성공.

## 후속 확인

- SSE는 현재 Next 서버 프로세스 메모리 기반이다. 여러 인스턴스로 수평 확장할 경우 Redis pub/sub 같은 외부 브로커가 필요하다.
- 브라우저 간 즉시 갱신은 API 성공 이후 발행되며, 네트워크가 끊긴 세션은 다음 조회 또는 재접속 시 최신 데이터를 다시 불러온다.
