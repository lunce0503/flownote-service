# 모바일 그림판 툴바 터치 불안정

## 증상

- 모바일 브라우저에서 그림판 툴바 버튼을 터치해도 한 번에 동작하지 않는 것처럼 보인다.
- 되돌리기 같은 주요 툴바 버튼이 모바일 화면에서 찾기 어렵거나 사라진 것처럼 보인다.
- 텍스트 상자에 긴 내용을 입력하면 상자 크기가 내용 증가를 따라가지 못한다.

## 원인

- 캔버스 루트가 터치 제스처를 강하게 제어하면서 툴바 입력과 캔버스 입력이 충돌할 수 있었다.
- 터치 `pointerup`에서 버튼 동작을 실행한 뒤 브라우저 합성 `click`이 이어지면 토글류 버튼은 두 번 실행되어 원래 상태로 돌아갈 수 있었다.
- 텍스트 상자의 크기 계산이 입력 내용 변경 시점에 갱신되지 않았다.

## 수정 방향

- 툴바와 편집 입력은 캔버스 터치 차단 대상에서 제외한다.
- 툴바 버튼의 터치 영역을 최소 48px로 맞추고, 터치/펜 입력은 작은 이동 범위 안의 `pointerup`에서 한 번만 실행한다.
- 터치 실행 직후 발생하는 합성 `click`은 짧은 시간 동안 무시해 중복 토글을 방지한다.
- 텍스트 입력 변경과 편집 확정 시 텍스트 상자 크기를 내용에 맞춰 자동 확장한다.
