# 피드백 자동화 구성 오류

- 증상: 피드백 수집 서비스는 성공하지만 2026-10-05~06 접수된 3건의 분석이 종료 코드 78로 실패 큐에 보관됨.
- 원인: 이전 FactChat 프로필에 필요한 환경 키가 systemd 사용자 관리자 재시작 이후 유지되지 않음. dispatcher는 실패를 큐에 기록하고 수집 서비스에는 처리 개수만 반환하므로 service 성공만으로 분석 성공을 판단할 수 없음.
- 수정 방향: 이미 적용된 기본 OpenAI 프로필·ChatGPT 로그인 캐시와 `gpt-6.1-sol`을 유지. 보관된 피드백을 현재 코드와 대조해 구현·검증·배포한 뒤 완료 큐와 구조화 결과에 처리 근거를 보존.
- 원본 피드백 및 인증값은 이 기록에 포함하지 않음.
