# Linux 릴리즈 패키지의 터치 리모컨 안내 누락

0.6.0 개발 아카이브와 `scripts/package-linux.sh`를 검사해 `docs/TOUCH.md`가 복사 목록에 없음을 재현했다. CLI 안내에서 이 문서를 참조하므로 압축을 푼 사용자의 오프라인 안내 링크가 깨진다.

0.6.0 태그 검증 실행 40659435107을 공개 게시 전에 취소했고 태그를 덮어쓰지 않았다. 0.6.1/versionCode 11에서 안내 파일을 복사하고 패키징의 `test -f`로 필수 포함을 검사한다. 다운로드한 공개 tar.gz에서도 이 파일의 존재를 재검증한다. 검증·릴리즈 결과는 [릴리즈 보고서](../report/2026-10-28-0848-touch-remote-github-release.md)에 남긴다.
