# 책장 PDF 크기와 기존 앱 내보내기 한도 불일치

- 증상: 웹 책장은 최대 100MiB 원본을 보관하지만 기존 iOS는 8MiB, Android blob/data 저장은 32MiB까지여서 큰 책을 내보내지 못한다.
- 원인: 전체 파일을 하나의 base64 메시지/메모리 배열로 변환하던 기존 공용 내보내기 경로를 책장에도 사용했다.
- 수정: PDF만 iOS의 확인 응답 기반 256KiB 메시지와 Android의 256KiB Blob slice 읽기로 private cache에 기록한다. 사용자의 OS 공유/저장 선택을 거쳐 출력하고 부분 파일을 정리한다. 다른 형식의 기존 제한을 완화하지 않는다.
- 경계: 고정 HTTPS origin, 정확한 iOS 스키마, UUID·순서·크기·헤더, 안전한 이름을 검사한다. 앱 자료 저장소나 원본을 지우지 않는다. PDF 서버 동기화는 추가하지 않는다.
- 검증: 100MiB 양끝 해시, 잘못된 origin/스키마/순서/헤더, 미완료/취소/확인 대기 중 이동/공유 중 취소, iPad WebKit 브리지 통합, Android 시스템 선택·이전 APK에서 새 APK로 자료 보존, Windows 설치형·포터블 검증. 실행 결과와 배포 ID는 이번 앱 릴리스 보고서에 기록한다. 실제 iPad 공유 시트는 하드웨어 확인 범위다.
