데스크톱에서도.

웹과 Android에서 사용하던 노트, 캔버스, 플래너를 Windows 앱에서 이어가세요. 같은 계정으로 로그인하면 같은 자료를 사용할 수 있습니다.

Windows 설치 파일 다운로드 설치 없이 사용하는 포터블 ZIP

버전 1.1.1 · Windows 10/11 · 64비트(x64)

설치 방법

  1. 설치 파일을 내려받고 실행하세요.
  2. 설치 위치를 선택한 뒤 설치를 완료하세요. 현재 사용자 계정에 설치됩니다.
  3. Flownote를 열고 기존 계정으로 로그인하세요.

포터블 버전은 ZIP 전체를 압축 해제한 뒤 Flownote.exe를 실행하세요. 인터넷 연결이 필요합니다.

자동 업데이트

1.1.1부터 앱 시작·재개 시와 매시간 새 버전을 확인하고, 서명·SHA-256 검증 후 자동 다운로드합니다. 도움말 → 업데이트에서 진행 상태, 변경 내용, 이력과 재시도를 확인하세요.

설치형은 저장을 마친 뒤 ‘종료하고 설치’를 눌러 설치 프로그램을 실행합니다. 포터블은 받은 ZIP을 새 폴더에 압축 해제하고 실행하세요. 포터블 파일을 자동 교체하지는 않습니다. 기존 로그인·초안·자료는 유지됩니다.

기존 1.0.0에는 자동 업데이트가 없고 초기 1.1.0은 다운로드 오류가 있어, 이번 1.1.1은 한 번 직접 설치해야 합니다.

이번 릴리즈에는 Windows 게시자 코드서명이 없습니다. 파일 무결성은 릴리즈의 SHA256SUMS.txt로 확인할 수 있습니다.
